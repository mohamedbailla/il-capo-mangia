# Restaurante IL Capo Mangia
- One-line positioning: Premium Italian restaurant website for IL Capo Mangia in Almería, Spain with full reservation system
- Target users: Restaurant customers (public), restaurant owner (admin)
- Core features:
  1. Public landing page: Hero, About, Menu (6 categories), Gallery, Testimonials, Reservations form, Location, Contact, Opening Hours
  2. Reservation system: form → DB → admin management
  3. Admin panel: view/search/confirm/cancel/delete reservations
- Important features (P1):
  1. Reservation availability logic (days + time slots)
  2. Admin dashboard with search and status management
- Device strategy: adaptive
- Design style: Warm sophisticated Italian-Mediterranean — dark hero with warm amber/gold accents, elegant serif headings, premium feel
- Technical constraints: Next.js App Router, Drizzle ORM + PostgreSQL, Tailwind CSS 4
- Nova Agent: not needed
- Completed: DB schema, images, brief
- Current iteration: Full website build — all sections + admin panel
